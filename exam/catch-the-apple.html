Catch the Apple, Avoid the Rock

Tangkap Apel, Hindari Batu — buat satu permainan utuh dari nol

1 Permainan yang Harus Kamu Buat

Kamu membuat permainan menangkap buah. Aturan mainnya:

  • Pemain menggerakkan mangkuk ke kiri dan ke kanan memakai tombol panah kiri dan panah kanan. Mangkuk tidak boleh keluar dari panggung.
  • Apel jatuh dari atas ke bawah. Kalau tertangkap mangkuk: terdengar bunyi koin, skor bertambah 1, lalu apel kembali ke atas di tempat acak.
  • Batu juga jatuh dari atas. Kalau batu kena mangkuk, tulisan GAME OVER muncul dan permainan berhenti.
  • Apel dan batu yang lolos sampai bawah panggung otomatis naik lagi ke atas di tempat acak.

3 Langkah Pengerjaan

Kerjakan berurutan dari Langkah 1 sampai Langkah 5. Setiap kotak berwarna adalah satu blok yang harus kamu cari di palet dan kamu susun persis seperti urutannya. Blok yang ditulis menjorok ke dalam berarti diletakkan di dalam blok di atasnya.

Langkah 1 Backdrop — Latar Belakang
  1. Klik tombol Choose a Backdrop di pojok kanan bawah.
  2. Pilih satu backdrop bebas (contoh: Blue Sky).
Hasil: panggung tidak lagi berwarna putih polos. Backdrop tidak perlu diberi kode apa pun.
Langkah 2 Sprite Bowl — Mangkuk yang Digerakkan Pemain

Tambahkan sprite Bowl, lalu geser ke bagian bawah panggung. Buat 1 script berikut.

Script 1 — Mangkuk bergerak kiri–kanan dan tidak keluar panggung
  1. Pasang when ⚑ clicked sebagai blok paling atas.
  2. Di bawahnya pasang forever. Semua langkah berikutnya diletakkan di dalam forever.
  3. Di dalam forever, pasang if < > then. Isi lubang segi enamnya dengan key (right arrow) pressed?. Di dalam if ini, susun:
    1. change x by (10)
    2. if < > then dengan syarat touching (edge)?, dan di dalamnya:
      1. change x by (-10)
  4. Masih di dalam forever, tepat di bawah if yang tadi (bukan di dalamnya), pasang if < > then kedua dengan syarat key (left arrow) pressed?. Di dalamnya susun:
    1. change x by (-10)
    2. if < > then dengan syarat touching (edge)?, dan di dalamnya:
      1. change x by (10)
Hasil: mangkuk bergerak saat tombol panah ditekan, lalu berhenti begitu menyentuh tepi panggung — karena langkahnya langsung dibatalkan dengan nilai kebalikannya.
Langkah 3 Sprite Apple — Apel yang Menambah Skor

Tambahkan sprite Apple dan suara Coin di tab Sounds. Sprite ini punya 3 script terpisah yang berdiri sendiri-sendiri.

Script 1 — Apel jatuh, lalu naik lagi ke atas
  1. when ⚑ clicked
  2. forever, dan di dalamnya:
    1. change y by (-5)
    2. if < > then dengan syarat operator ( ) < ( ). Kolom kiri diisi blok y position, kolom kanan diketik -160. Di dalam if ini:
      1. go to (random position)
      2. set y to (180)
Hasil: apel turun terus. Begitu posisi y lebih kecil dari −160 (sudah di dasar panggung), apel pindah ke tempat acak lalu diangkat lagi ke atas (y = 180).
Script 2 — Apel tertangkap mangkuk → skor bertambah
  1. when ⚑ clicked
  2. forever, dan di dalamnya:
    1. if < > then dengan syarat touching (Bowl)?. Di dalam if ini, urut dari atas ke bawah:
      1. start sound (Coin)
      2. change (Score) by (1)
      3. go to (random position)
      4. set y to (180)
Hasil: saat apel menyentuh mangkuk terdengar bunyi koin, skor naik 1, dan apel langsung dikembalikan ke atas.
Script 3 — Skor dimulai dari nol
  1. when ⚑ clicked
  2. set (Score) to (0)
Hasil: setiap kali bendera hijau diklik, skor kembali ke 0 — tidak melanjutkan skor permainan sebelumnya.
Langkah 4 Sprite Rock — Batu yang Mengakhiri Permainan

Tambahkan sprite Rock (batu). Sprite ini punya 2 script terpisah.

Script 1 — Batu jatuh, lalu naik lagi ke atas
  1. when ⚑ clicked
  2. set y to (180)  (supaya batu selalu mulai dari atas panggung)
  3. forever, dan di dalamnya:
    1. change y by (-5)
    2. if < > then dengan syarat ( ) < ( ): kolom kiri y position, kolom kanan -160. Di dalamnya:
      1. go to (random position)
      2. set y to (180)
Hasil: batu jatuh sama seperti apel dan berulang terus tanpa henti.
Script 2 — Batu kena mangkuk → permainan berakhir
  1. when ⚑ clicked
  2. forever, dan di dalamnya:
    1. if < > then dengan syarat touching (Bowl)?. Di dalam if ini:
      1. broadcast (GAME OVER)
      2. stop (all)
Hasil: begitu batu menyentuh mangkuk, sprite lain diberi tahu lewat pesan GAME OVER, lalu seluruh script di proyek dihentikan.
Perhatikan: broadcast (GAME OVER) harus berada di atas stop (all). Kalau terbalik, pesan tidak pernah terkirim karena permainan sudah berhenti lebih dulu.
Langkah 5 Sprite Game Over — Tulisan Penutup

Buat sprite baru lewat Paint, gunakan alat Text (T) dan tulis Game Over. Ganti nama sprite menjadi Game Over, lalu tambahkan suara Laugh3 di tab Sounds. Sprite ini punya 2 script terpisah.

Script 1 — Tulisan disembunyikan saat permainan dimulai
  1. when ⚑ clicked
  2. hide
Script 2 — Tulisan muncul saat menerima pesan GAME OVER
  1. when I receive (GAME OVER)  (blok topi, bukan when ⚑ clicked)
  2. start sound (Laugh3)
  3. show
Hasil: tulisan Game Over tersembunyi selama permainan berjalan, dan baru muncul bersama bunyi tawa ketika batu mengenai mangkuk.

4 Uji Coba Sebelum Dikumpulkan

Klik bendera hijau, lalu periksa satu per satu. Semua kotak harus tercentang.

  • Skor di panggung menunjukkan 0 setiap kali bendera hijau diklik.
  • Mangkuk bergerak ke kanan saat tombol panah kanan ditekan, dan ke kiri saat panah kiri ditekan.
  • Mangkuk berhenti di tepi panggung, tidak bisa keluar layar.
  • Apel jatuh dari atas ke bawah tanpa berhenti.
  • Apel yang sampai dasar panggung naik lagi ke atas di tempat yang berbeda-beda.
  • Saat apel masuk mangkuk: terdengar bunyi Coin dan skor bertambah 1.
  • Batu ikut jatuh dan berulang seperti apel.
  • Saat batu kena mangkuk: permainan berhenti dan tulisan Game Over muncul.
  • Nama variabel persis Score, nama pesan persis GAME OVER.
  • File disimpan dengan nama: NamaKamu_Kelas_CatchTheApple.sb3.

B. Konsep yang diuji

KonsepYang harus kamu pahami
Urutan (sequence)Blok dijalankan dari atas ke bawah. Menukar urutan blok mengubah hasilnya.
PerulanganKapan memakai forever, dan mengapa blok gerak harus berada di dalamnya, bukan di bawahnya.
PercabanganMembaca if sebagai “jika benar, kerjakan isinya”. Termasuk if di dalam if (bersarang) pada sprite Bowl.
Sistem koordinatSumbu x (−240 s.d. 240) untuk kiri–kanan, sumbu y (−180 s.d. 180) untuk atas–bawah. y negatif besar = dasar panggung.
Beda change dan setchange menambah dari nilai sekarang; set mengganti langsung dengan nilai baru. Berlaku untuk posisi maupun variabel.
Sensor & kondisiBlok segi enam (boolean) hanya bisa masuk ke lubang segi enam pada if.
VariabelMembuat variabel, mengatur nilai awal, dan menambah nilainya saat kejadian tertentu.
Pesan (broadcast)Cara satu sprite menyuruh sprite lain bekerja — pengirim dan penerima harus memakai nama pesan yang sama persis.
Banyak script sekaligusSatu sprite boleh punya beberapa script when ⚑ clicked yang berjalan bersamaan.
